## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development servers:**
   ```bash
   npm run dev:full
   ```

3. **Access the application:**
   - Frontend: http://localhost:5173
   - Backend API: http://localhost:3002

## 🔧 Key Features

- **Multi-tenant Architecture** - Support for multiple businesses
- **Role-Based Access Control** - Fine-grained permissions
- **Real-time Inventory Tracking** - Stock management with batch tracking
- **Sales Management** - Complete sales workflow with refunds
- **Analytics & Reports** - Comprehensive reporting and insights
- **PWA Support** - Progressive Web App capabilities
- **Security** - Bcrypt hashing, rate limiting, CORS protection
